# AlineReporteArduino

Mano robótica impresa en 3D controlada con Arduino UNO, cinco servomotores y un teclado matricial 4x4.

- `codigo/`: programas de Arduino (`mano_robotica_teclado.ino` y `prueba_servos.ino`).
- `simulador/`: simulador web que ejecuta el código real en un Arduino UNO emulado y mueve una mano 3D. Ver `simulador/LEEME.md` y `simulador/README.html`.
- `Reporte_tecnico_mano_robotica.pdf` / `.docx`: reporte técnico del proyecto final.
